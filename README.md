# Sistema Bancario em Java

Uma aplicação em Java que simula operações básicas de uma conta bancária, desenvolvida como projeto de consolidação de conhecimentos.

Funcionalidades

Consultar saldo da conta
Receber valores (depósitos)
Transferir valores (saques)
Validação de saldo suficiente
Menu interativo
Como usar

Execute a aplicação
Escolha uma das opções do menu:
1: Consultar saldos
2: Receber valor
3: Transferir valor
4: Sair
Siga as instruções na tela
